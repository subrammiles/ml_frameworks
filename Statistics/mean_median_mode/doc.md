# Mean, median, and mode

These are measures of **center**: they describe a typical value in a dataset.

## Mean

The arithmetic average: add all values, then divide by the number of values.
The mean uses every value, so unusually large or small values can move it.

## Median

Sort the values and take the middle one. With an even number of values, average
the two middle values. The median is less affected by extreme values than the
mean.

For `3, 3, 3, 3, 5, 5, 6, 8, 9, 10`, the middle pair is 5 and 5, so the median
is 5.

## Mode

The most frequently occurring value. A dataset can have one mode, multiple
modes, or no repeated value.

For `2, 2, 2, 2, 5, 5, 6, 8, 11`, the mode is 2.
